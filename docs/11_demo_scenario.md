# 11. 데모 시나리오

## 1. 시연 슬로건

**“증상 한 줄 → AI 구조화 → 교범 근거 → 3D로 필터까지.”**

## 2. 사전 준비

1. Docker Compose 또는 FE/BE 로컬 기동
2. Demo Mode ON (심사장 네트워크 불안정 대비)
3. GLB 사전 로드 확인
4. 더미 고지 문구 화면 노출 확인

## 3. 대표 스크립트 (3~5분)

| 분 | 행동 | 기대 |
|---|---|---|
| 0:00 | 초기 화면, 전체 기체 | SCR-01 |
| 0:20 | 질의 입력: `엔진 오일 압력이 낮고 경고등이 점등되었어.` | SCR-02 |
| 0:40 | 우측: ENGINE_OIL / HIGH / OIL_FILTER | Diagnosis |
| 0:50 | 중앙: 엔진 구역 하이라이트 | SCR-03 |
| 1:10 | 구역 클릭 → 카메라 이동 | SCR-04 |
| 1:30 | 패널 열기 → 내부 노출 | SCR-05~06 |
| 1:50 | 오일 필터 하이라이트 | SCR-07 |
| 2:10 | 교범 탭: 장·절·페이지 + is_dummy | SCR-08 |
| 2:30 | PHM: 28psi 등 모의값 | SCR-09 |
| 2:50 | 가이드 단계 진행 ↔ 3D | SCR-10 |
| 3:20 | 정비결과 등록 | SCR-11 |
| 3:40 | Reset 후 동일 시나리오 재현 | SCR-12→03 |

## 4. 고정 응답 키워드

| 키워드 | demo id | view_target_id |
|---|---|---|
| 오일 압력, 경고등 | DEMO-OIL-001 | ENGINE_OIL_SYSTEM |
| 오일 필터, 오염 | DEMO-OIL-002 | ENGINE_OIL_FILTER |
| 랜딩기어 | DEMO-LG-001 | LANDING_GEAR_OVERVIEW (P1) |
| 로터 진동 | DEMO-ROTOR-001 | MAIN_ROTOR_OVERVIEW (P1) |

## 5. 실패 시 즉시 조치

1. Demo Mode 강제 ON
2. 사전 캐시 응답으로 우측/3D 수동 트리거(개발자 핫키 옵션)
3. GLB 실패 시 기존 PNG 트윈 폴백은 선택(권장: 오류 배너 + 박스 프록시)

## 6. 심사위원 고지
